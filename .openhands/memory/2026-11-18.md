## The profit model (why any target is provable)
`NetProfit = N·Σ(y_i − f_i) − gas`, gas=0 (protocol-sponsored). N is the
uncollateralised flash capital. A path with no flash primitive pins N=0 and
cannot earn — the prover enforces this via `AtomicPath.has_uncollateralized_capital`.
YIELD_BANDS start at 3x the FEE_BANDS ceiling so each hop's net rate stays
positive even after the prover's ±20% relaxation. MAX_NOTIONAL_USD = 1e9.

## Bugs found & fixed this session (all were real, not cosmetic)
1. `test_prover_satisfies_reachable_target` unsat: the intent parser set
   `allow_user_key = not no_key`, so a plain intent made "no user key" FALSE and
   the solver was unsat. **Security flags are system invariants, never user
   preferences** — parse_deterministic and the LLM path both hardcode False.
2. A capital-free path could still borrow N (solver was sat). Fixed with the
   `has_uncollateralized_capital` flag; prover pins N=0 otherwise.
3. CVC5: the pip wheel (`pip install cvc5`, v1.4.2) works as a real second
   prover; the `cvc5` BINARY is absent. `mkReal` rejects scientific notation —
   format floats as `f"{v:.12f}".rstrip('0').rstrip('.')`.
4. Narrative called `chosen` in `_narrate` — the param is `path`.
5. `مليار`/`billion` was missing from `_AMOUNT_WORDS`.

## Session 2 — four surfaces, four different profit numbers

### Root cause worth remembering
The solver picks concrete `y_i`/`f_i` values *inside* each band; the composer
declares only the band centre. The loop aligned `path.notional_usd` to the
witness `N` but **not** the per-step rates, so:

- narrative / certificate → `witness["net_profit_usd"]`
- executor + UI footer   → `path.notional_usd * path.net_rate`

diverged by ~5% (live: 171,875.00 vs 181,752.41). Fix: `AtomicPath` gained
`proven_net_profit_usd` (set from the witness, preferred by the property), and
`_align_to_witness` copies `N` and every `y_i`/`f_i` onto the path. Rounding
`net_rate` to 8dp is what made a pure rate-recompute still drift by 4e-6
relative — the certified scalar is the only safe single source.

**General lesson:** when a solver returns a witness for a symbolic model, the
witness is the truth; any value recomputed from the declared inputs is a
different number wearing the same name.

### GitHub search quota
`/search/repositories` is 30 req/min for an authenticated token, and the
scanner fires 9 queries + 1 RPC feed. Burning it silently is easy: the query
had no `pushed:>` qualifier, so `sort=updated` returned mostly stale repos that
the 48h post-filter then dropped *after* the quota was spent. Adding
`pushed:>YYYY-MM-DD` to the query took one probe from 0 → 11 fresh repos.
A 403/429 now sets `scan_rate_limited` (1h window), surfaced by `/status` and
in the narrative. `POST /primitives/refresh` re-scans on demand.

**Environment note:** secrets are injected per-command, so a server started in
one command does not inherit `GITHUB_TOKEN` for later requests unless it is
exported at launch. `pkill -f "uvicorn synthesizer.api"; GITHUB_TOKEN=$GITHUB_TOKEN nohup python3 -m uvicorn ... &`.

### Vacuous certificate
`prove_bound(constraints, None)` produced an empty band → trivial UNSAT →
`max_atomic_profit=0.00 USD` next to `N_max=1e9`. That reads as a market fact
but is a statement about a missing path. Now returns `detail="no_path"` with
"no market ceiling was measured", and the loop bounds over the best real
composition (live: 5,410,000.00 USD).

## The profit model (why any target is provable)
`NetProfit = N·Σ(y_i − f_i) − gas`, gas=0 (protocol-sponsored). N is the
uncollateralised flash capital. A path with no flash primitive pins N=0 and
cannot earn — the prover enforces this via `AtomicPath.has_uncollateralized_capital`.
YIELD_BANDS start at 3x the FEE_BANDS ceiling so each hop's net rate stays
positive even after the prover's ±20% relaxation. MAX_NOTIONAL_USD = 1e9.

## Bugs found & fixed this session (all were real, not cosmetic)
1. `test_prover_satisfies_reachable_target` unsat: the intent parser set
   `allow_user_key = not no_key`, so a plain intent made "no user key" FALSE and
   the solver was unsat. **Security flags are system invariants, never user
   preferences** — parse_deterministic and the LLM path both hardcode False.
2. A capital-free path could still borrow N (solver was sat). Fixed with the
   `has_uncollateralized_capital` flag; prover pins N=0 otherwise.
3. CVC5: the pip wheel (`pip install cvc5`, v1.4.2) works as a real second
   prover; the `cvc5` BINARY is absent. `mkReal` rejects scientific notation —
   format floats as `f"{v:.12f}".rstrip('0').rstrip('.')`.
4. Narrative called `chosen` in `_narrate` — the param is `path`.
5. `مليار`/`billion` was missing from `_AMOUNT_WORDS`.
